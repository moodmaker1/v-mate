시각 능력 (Vision)

화면에 무엇이 있는지 물어보세요. AI가 실시간으로 활성 창을 분석하고 이해하여 답변합니다.

음성 상호작용

자연스럽게 말로 대화하세요. 저지연 음성 인식(STT)과 텍스트 음성 변환(TTS)으로 매끄러운 대화 경험을 제공합니다.

Live2D 아바타
