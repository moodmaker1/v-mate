화면 인식 및 분석

AI에게 말로 설명할 필요 없이, 보고 있는 화면을 그대로 보여주세요. 0.1초 이내 고해상도 화면 캡처로 즉시 분석합니다.

  • mss 라이브러리 기반 초고속 캡처
  • Vision 모델을 통한 실시간 분석
  • 코딩, 디자인, 학습 등 다양한 활용
⌨️

글로벌 단축키

마우스로 창을 전환할 필요 없이 Cmd+Shift+S로 즉시 AI와 소통하세요. 어떤 애플리케이션에서든 작동합니다.

  • OS 레벨 키보드 이벤트 후킹
  • 작업 흐름을 끊지 않는 Seamless Workflow
  • pynput 라이브러리 기반 안정적 동작

Notion 연결하기

3단계로 간단하게 Notion과 연결하세요

1

Notion Integration 생성하기

Notion에서 Integration을 생성하여 API 키를 발급받습니다.

[스크린샷: API 통합 목록 페이지]
[스크린샷: 새 API 통합 생성 폼]
[스크린샷: API 통합 생성 완료 모달]

단계 1: Notion에 로그인 후 My Integrations 페이지로 이동하여 "새 API 통합" 카드를 클릭하세요.
단계 2: Integration 이름(예: "v-mate")을 입력하고 워크스페이스를 선택한 후 "저장" 버튼을 클릭하세요.
단계 3: 생성 완료 모달이 나타나면 "API 통합 설정 구성" 버튼을 클릭하세요.

Notion으로 이동
2

Integration Secret 복사하기

생성된 Integration의 "프라이빗 API 통합 시크릿"을 복사합니다. 이 키는 한 번만 표시되므로 안전하게 보관하세요.

[스크린샷: Integration 설정 페이지 - Secret 표시하기]
[스크린샷: Secret 복사 화면]

단계 1: Integration 설정 페이지의 "구성" 탭으로 이동하세요. "프라이빗 API 통합 시크릿" 섹션에서 "표시하기" 버튼을 클릭하여 Secret을 확인하세요.
단계 2: Secret이 표시되면 "복사" 버튼을 클릭하여 Secret을 복사하세요. 이 키는 한 번만 표시되므로 안전하게 보관하세요.

3

페이지 생성 및 Integration 연결

Notion에서 빈 페이지를 생성하고, 해당 페이지에 Integration을 연결합니다.

[스크린샷: Notion 빈 페이지 생성 화면]

단계 1: Notion 워크스페이스에서 좌측 사이드바의 "+ New page" 버튼을 클릭하거나, 기존 페이지에서 새 페이지를 생성하세요. 페이지 제목을 입력하세요 (예: "v-mate 기록").
단계 2: 생성한 페이지 우측 상단의 "..." 메뉴를 클릭하고 "Connect" 옵션을 선택한 후, 생성한 Integration(예: "v-mate")을 선택하여 연결하세요.
단계 3: 연결이 완료되면 페이지 URL에서 페이지 ID를 확인할 수 있습니다. URL의 마지막 32자리 문자열이 페이지 ID입니다 (예: notion.so/v-mate-2bf206a02abe80e283baf9d6c700af2e).

페이지 URL 예시: notion.so/workspace/2bf206a02abe80e283baf9d6c700af2e
