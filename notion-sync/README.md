# 📚 Notion Sync - 자동 노션 정리

v-mate의 자동 노션 정리 기능입니다. 드래그한 내용을 AI가 과목별로 자동 분류해서 노션 데이터베이스에 저장합니다.

## 🚀 빠른 시작

### 1️⃣ Notion Integration 만들기

1. https://www.notion.so/my-integrations 접속
2. **"+ New integration"** 클릭
3. 이름: `v-mate` 입력
4. **Capabilities** 설정:
   - ✅ Read content
   - ✅ Insert content
   - ✅ Update content
5. **"Submit"** 클릭
6. **Integration Token 복사** (secret_으로 시작)

### 2️⃣ Notion 데이터베이스 만들기

1. Notion에서 새 페이지 생성
2. `/database` 입력 → **"Table - Inline"** 선택
3. 데이터베이스 이름: `📚 학습 자료` (원하는 이름 가능)

4. **속성(Properties) 설정:**

| 속성명 | 타입 | 설명 |
|--------|------|------|
| Name | Title | 제목 (자동 생성: [과목] - 날짜) |
| 과목 | Select | 과목/분야 (AI가 자동 분류) |
| 날짜 | Date | 저장 날짜 |
| 출처 | URL | 원본 페이지 링크 |
| 페이지 제목 | Text | 원본 페이지 제목 |

5. **Integration 연결:**
   - 데이터베이스 우측 상단 `···` 클릭
   - **"Connections"** → **"Connect to"**
   - `v-mate` 선택

6. **Database ID 복사:**
   - 데이터베이스를 전체 페이지로 열기
   - URL 확인: `notion.so/[여기가 Database ID]?v=...`
   - 예: `notion.so/2b3206a02abe80e28d36ec0f9b64b748?v=...`
   - Database ID: `2b3206a02abe80e28d36ec0f9b64b748`

### 3️⃣ v-mate 설정

1. Chrome 툴바에서 v-mate 아이콘 클릭
2. **"📚 Notion 설정"** 섹션으로 스크롤
3. **Notion Integration Token** 입력
4. **Database ID** 입력
5. **"연결 테스트"** 클릭 → ✅ 연결 성공 확인
6. **"Notion 설정 저장"** 클릭

### 4️⃣ 사용하기!

1. v-mate 팝업에서 **"📚 노션 정리"** 모드 선택
2. 웹페이지 **새로고침 (F5)**
3. 텍스트 **드래그** (3글자 이상)
4. **📚 초록색 아이콘** 클릭
5. 팝업에서 내용 확인 (AI가 과목 자동 분류)
6. 메모 추가 (선택사항)
7. **"✅ 노션에 저장"** 클릭
8. 노션 데이터베이스에서 확인! 🎉

## 🎯 기능 설명

### 📌 AI 과목 자동 분류

GPT가 드래그한 텍스트와 페이지 맥락을 분석해서 자동으로 과목을 분류합니다.

**예시:**
- "데이터베이스 정규화" → `데이터베이스`
- "React Hook 사용법" → `웹개발`
- "Binary Search Tree" → `알고리즘`
- "영어 문법 설명" → `영어`

분류가 틀렸다면? → 팝업에서 직접 수정 가능!

### 📝 자동 정리 구조

노션에 저장되는 내용:

```
📚 [데이터베이스] - 2024-11-22

🔑 핵심 개념
━━━━━━━━━━━━━
[드래그한 텍스트]

💡 내 생각/질문
━━━━━━━━━━━━━
[사용자가 입력한 메모]

🔗 출처
━━━━━━━━━━━━━
[원본 페이지 링크]
```

### 🏷️ 최근 사용한 과목

자주 사용하는 과목은 드롭다운에서 바로 선택 가능!
- 최근 10개까지 자동 저장
- 클릭 한 번으로 선택

## 🐛 문제 해결

### "Notion 설정이 필요합니다" 오류

**해결:**
1. v-mate 팝업 열기
2. Notion 설정 섹션에서 Token과 Database ID 입력
3. "연결 테스트" 클릭해서 확인
4. 페이지 새로고침 (F5)

### "연결 실패" 오류

**원인:**
- Integration Token이 틀림
- Database ID가 틀림
- Integration이 데이터베이스에 연결되지 않음

**해결:**
1. Notion에서 Integration Token 재확인
2. Database ID 다시 복사 (URL에서)
3. 데이터베이스 `···` → Connections → v-mate 연결 확인
4. "연결 테스트" 다시 실행

### 아이콘이 나타나지 않음

**해결:**
1. v-mate 팝업에서 **"노션 정리"** 모드 선택 확인
2. 페이지 **반드시 F5 새로고침**
3. 3글자 이상 드래그
4. F12 → Console에서 `📚 v-mate notion mode activated` 확인

### AI 분류가 이상함

**해결:**
- 팝업에서 과목명 직접 수정
- 자주 사용하는 과목은 최근 목록에 저장됨
- 다음부터는 드롭다운에서 빠르게 선택 가능

## 💾 저장 데이터

### Chrome Storage
```javascript
{
  notionToken: 'secret_xxxxx',      // Integration Token
  notionDatabaseId: 'xxxxx',        // Database ID
  recentSubjects: ['데이터베이스', '알고리즘', ...]  // 최근 과목
}
```

### 보안
- ✅ Token은 브라우저에만 저장 (로컬)
- ✅ 서버에 전송하지 않음
- ❌ 암호화되지 않음 (Chrome Storage 기본 보안)

## 🎓 활용 예시

### 시나리오 1: 논문 읽기
```
1. 논문에서 중요한 개념 드래그
2. 📚 클릭 → "논문" 또는 구체적 과목명 입력
3. 메모: "이 개념 나중에 발표 때 쓸 것"
4. 저장 → 노션에서 언제든 찾아보기
```

### 시나리오 2: 온라인 강의
```
1. 강의 사이트에서 핵심 내용 드래그
2. 📚 클릭 → AI가 자동으로 과목 분류
3. 메모: "시험 출제 가능성 높음 ⭐"
4. 저장 → 시험 전 노션에서 총정리
```

### 시나리오 3: 코딩 공부
```
1. Stack Overflow 답변 드래그
2. 📚 클릭 → "프로그래밍" 자동 분류
3. 메모: "내 프로젝트에 적용해보기"
4. 저장 → 나만의 코드 스니펫 라이브러리
```

## 📊 Notion 데이터베이스 활용 팁

### 뷰(View) 만들기

**1. 과목별 뷰**
- Filter: 과목 = "데이터베이스"
- Sort: 날짜 (최신순)

**2. 이번 주 학습 뷰**
- Filter: 날짜 is within "This week"
- Group by: 과목

**3. 시험 준비 뷰**
- Filter: 과목 = "알고리즘"
- Sort: 날짜 (오래된 순)
- → 처음부터 복습!

### 태그 추가
- `중요` - 시험 출제 가능성 높음
- `복습 필요` - 아직 이해 안 됨
- `완료` - 이미 이해함
